# AVA • Digital Marketing Agency in Alappuzha & Across Kerala

A complete, high-performance, responsive digital marketing website built for **AVA**, a premier digital marketing agency based in **Alappuzha, Kerala**, partnering with businesses across all 14 districts.

Built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS**, and **Lucide React**.

---

## 🌟 Key Highlights & Features

- **Brand Identity**: Headquartered in **Alappuzha, Kerala**, serving businesses statewide.
- **Modern Clean Aesthetic**: High-contrast white background, deep slate typography, vibrant lime green accents (`#a3e635` / `#84cc16`), rounded cards, and smooth micro-interactions.
- **Full Marketing Services Architecture**:
  1. **360° Marketing**: Lead generation, unified multi-channel roadmap & conversion optimization.
  2. **Performance Marketing**: Google & Meta Ads, Click-to-WhatsApp campaigns, ROAS scaling.
  3. **Search Engine Optimisation (SEO)**: Local Kerala SEO, Google Maps rankings, technical audits.
  4. **Social Media Marketing**: Instagram, Meta Business Suite, reel strategy, creative calendars.
  5. **Website Design & Development**: Mobile-first, high-converting digital storefronts.
  6. **Brand Identity & Creative**: Packaging, creative positioning, visual guidelines.
- **Interactive Kerala Districts Coverage**:
  - Highlights **Alappuzha (HQ)** and all 14 districts (Ernakulam/Kochi, Kottayam, Kollam, Thiruvananthapuram, Thrissur, Kozhikode, Kannur, Malappuram, Palakkad, Pathanamthitta, Idukki, Wayanad, Kasaragod).
- **Interactive Contact & Lead Engine**:
  - **WhatsApp Direct Connect**: Opens WhatsApp with prefilled message including client name, district, and required service.
  - **Phone Callback Request**: Instant focus and consultation booking.
  - **Growth Blueprint Inquiries**: Audit and proposal generation.
  - Interactive validation and responsive form submission.
- **Full-Funnel Working Process**: 4-step framework (Audit, Plan, Tracking & Launch, Run & Improve).
- **Pricing & Growth Packages**: Starter (Local), Growth (Statewide), Scale (Dominance).
- **10 Comprehensive FAQs**: Clear answers covering ad account ownership, local SEO, WhatsApp ads, and reporting.
- **SEO & Social Optimization**:
  - Semantic HTML5 structure.
  - OpenGraph & Twitter Cards.
  - Dynamic viewport and accessibility support.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed on your machine.
- npm or yarn or pnpm.

### Installation

```bash
# Clone the repository
git clone https://github.com/aromalbabus404/digital_market.git

# Navigate to project folder
cd digital_market

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Build & Production

```bash
# Build production bundle
npm run build

# Start production server
npm start
```
